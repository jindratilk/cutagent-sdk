# Captions

Use a supplied time-aligned transcript, subtitle file, or a locally available native DaVinci Resolve transcription capability. If no local transcript route exists, ask for a transcript or use an explicitly available local tool; do not claim that CutAgent generated one.

Choose native subtitles for semantic or sidecar delivery and Text+ for designed editable on-screen captions. Preserve exact spoken wording unless the user authorizes paraphrase. Align cues to the actual timeline, review speaker changes and line breaks, and inspect beginning, middle, and end of the rendered result. A transcript alone does not prove the caption timing or visual readability.
