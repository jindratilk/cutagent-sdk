# Fusion

Build a readable settled frame before animation. Use native Text+ for editable copy and a named, understandable node graph for visual work. Confirm the selected clip and composition; inspect tool types and input IDs through the installed SDK, CutAgent CLI reference, or live Fusion state instead of guessing them from a visual effect name.

Map timeline record time to composition frames using actual clip placement and source timing. Inspect keyframes and modifier behavior at multiple times. A `.setting` file is a local editable template only when DaVinci Resolve imports it and the resulting graph works. Keep user supplied images as separate media where editability matters. Verify node structure, representative frames, and a short native render for motion or compositing claims.
