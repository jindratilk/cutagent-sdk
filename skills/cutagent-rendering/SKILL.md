# Rendering

Confirm timeline, range, format, dimensions, frame rate, audio, filename, and destination against the delivery brief. Read the installed SDK or public CutAgent CLI reference for supported presets and render-job lifecycle. Check that output paths are writable and do not overwrite an unrelated file without the user's intent.

Wait for the actual terminal render state and check that the expected file exists. Probe the rendered video and audio, then inspect representative frames and listen where relevant. Report partial exports and warnings as such; a job identifier or process exit is not a delivered video.
