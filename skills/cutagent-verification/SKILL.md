# Verify the outcome

Match evidence to the claim. Structural readback can prove timeline and node state, a still can prove one frame's composition, multiple frames or playback can prove motion, audition can assess sound, and a probed/rendered file can prove delivery. An SDK operation terminal, CLI exit code, or one screenshot is only its own evidence.

After a mutation, refresh the affected project or timeline state. For picture changes inspect the changed interval and neighboring edits. For graphics sample entrance, settled hold, and exit. For sound listen at boundaries and in the intended mix. For exports inspect the actual output file. Report exact checks performed and any unverified quality, platform, edition, or source limitation.
