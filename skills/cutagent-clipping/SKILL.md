# Clipping

Deliver a small set of self-contained moments with clear value. Do not lower the editorial bar to fill a requested count.

## Cover the complete source

Honor the audience, platform, count, duration, language, and format when supplied. Otherwise infer the likely goal from the content without automatically adding captions, B-roll, music, graphics, or reframing.

Review the entire source chronologically before final selection. Use a time-aligned transcript for speech-led material, a motion-and-sound pass for visual material, or both. For long sources, keep a coverage ledger across overlapping windows so no span is skipped or judged twice.

Record promising passages with their original timeline range, central idea, opening, payoff, context dependency, speaker or action, and any picture or sound question. Compare all candidates only after coverage is complete.

## Select moments that survive alone

Prefer a strong claim, unexpected fact, useful mechanism, personal admission, transformation, prediction, conflict, perspective shift, memorable detail, natural viewer question, genuine emotion, humor, or visible proof.

A final moment should establish its subject quickly, develop one idea, resolve naturally, preserve the speaker's meaning, and have usable picture and sound. Reject passages that require hidden context, repeat a stronger candidate, wander without payoff, or become misleading when shortened.

Choose variety across a set. When two passages make the same point, retain the version with the cleanest wording, delivery, boundaries, and media.

## Set honest boundaries

Start as close as possible to the curiosity, tension, question, or result while retaining the shortest context needed for grammatical and semantic clarity. Remove disposable greetings, technical talk, false starts, and repeated setup; preserve intentional pauses, character, nuance, and reactions.

End after the answer, result, punchline, lesson, or meaningful response. Never cut inside a word, before a promised explanation, or during an incomplete action. Let the idea determine duration unless the user set a hard limit; report when that limit forces a compromise.

Verify every shortlisted range against the original picture and sound. A strong transcript line can fail in performance, overlap, sync, or motion, while an unremarkable sentence can become compelling in context.

## Build one timeline per moment

For local execution, read `cutagent-editing`, `cutagent-projects`, `cutagent-verification`; check the installed SDK declarations, public CutAgent CLI command cards, and live capabilities for exact operations.

Create one distinctly named timeline per selected moment from original project media. Preserve required video, audio, sync, multicam state, frame rate, and settings. Keep original record ranges and media source ranges distinct, avoid overwriting existing timelines, and preserve the source edit.

## Review and report

Watch and audition each complete result. Confirm that it contains one idea, works without preceding context, begins and ends cleanly, preserves meaning and synchronization, and contains no avoidable duplicate. Structural evidence cannot prove intelligibility or an inaudible join.

Report each timeline with its central idea, duration, original range, moment type, and reason for selection. State rejected near-duplicates, any requested count not met, and every remaining picture or listening limitation.
