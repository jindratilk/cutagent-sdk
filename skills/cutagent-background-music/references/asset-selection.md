# Choose a local music asset

Start with music supplied by the user or already available in a local folder or the DaVinci Resolve Media Pool. Confirm its license and any attribution requirement before use. Do not infer permission from a filename, online preview, or the fact that a file can be downloaded.

Define the cue's purpose, mood, energy, vocals, useful duration, and ending. Audition a small shortlist against the actual cut. Check whether the source has enough material for a phrase-aligned entrance and exit; prefer an alternate mix or local source region when it does not.

Import the selected file through the installed SDK or CutAgent CLI, place it on a named audio track, and inspect the imported identity and timeline range. Shape the mix with `cutagent-audio` and verify the result with `cutagent-verification`. Report the asset's origin, license, attribution, and any unresolved rights question.
