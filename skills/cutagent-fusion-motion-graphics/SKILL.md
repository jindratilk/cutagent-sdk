# Fusion motion graphics

Make the message clear in the settled frame, then use motion to direct attention. Keep type, shapes, masks, and animation editable in Fusion.

## Compose the scene

Decide the focal phrase, supporting visual, palette, type hierarchy, and delivery format. Build a readable hero frame before adding entrances. Use the user's reference to measure line breaks, relative size, placement, color, and the timing of each visible event. A template is a starting point; its default style is not a match to the reference.

Read `references/design-and-layout.md` for typography, cards, diagrams, or reference matching. Prefer fewer well-composed elements to a larger graph with no reading order. Check at the intended viewing size: thin strokes, crowded text, and soft contrast often disappear on a phone.

## Choreograph attention

Plan entrance, reading hold, and exit around the actual copy. Reveal supporting geometry before its label when that establishes meaning. Animate related objects together; stagger only when the order communicates something. Use a restrained settle for editorial work, an overshoot for an intentionally elastic object, and constant motion for a mechanical sweep.

Read `references/animation-and-timing.md` when choosing choreography or adapting a reference's rhythm. Give the viewer time to read before beginning the next competing movement. Match the entire movement, not just its final frame.

## Build with the installed SDK

For local execution, read `cutagent-fusion`; check the installed SDK declarations, public CutAgent CLI command cards, and live capabilities for exact operations.

Apply one coherent graph through the supported SDK route; use documented CutAgent CLI commands where they express a needed native feature. Do not infer SDK method names from a design term. Keep a complete connected output and a readable node layout.

Read `references/compositing-and-depth.md` for layering and spatial design. Study `assets/editable-card.setting` when its small native card structure helps explain the construction, then author the graph and animation for the actual brief. Replacing its text alone is not a new design. A downloaded movie used as a Loader remains baked media, not an editable reconstruction.

## Review the result

Check the settled frame for hierarchy, margins, glyphs, and contrast. Check motion across the entrance and exit for pops, detached elements, and unreadable holds. Use returned readback for factual graph changes and a short preview when judging movement. Fix the largest visible mismatch before adding decoration. Report any unmatched reference detail accurately.
