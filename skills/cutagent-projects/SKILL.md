# Projects and media

Confirm the intended project and timeline before importing or moving media. Names can repeat; prefer native IDs or exact source paths. Inspect source frame rates, durations, dimensions, audio channels, and media availability before constructing an edit. Organize bins and timelines with useful names while preserving unrelated folders and media.

Use the installed SDK's project and media-pool declarations or the public CutAgent CLI command cards for exact operations. Preview ambiguous selection before a move or mutation. For a new timeline, establish delivery rate and dimensions from the user's brief and source constraints before placing clips. Read back imported and relocated assets; a command result alone does not establish that DaVinci Resolve resolved the media.
