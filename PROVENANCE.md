# Source provenance

This repository contains the owner-authorized standalone extraction of the TypeScript SDK and selected local DaVinci Resolve implementation. First-party source is licensed AGPL-3.0-only. Earlier MIT grants remain valid for their original versions. Third-party components retain their own licenses; see THIRD_PARTY_NOTICES.

EXTRACTION_INVENTORY.json and native/SOURCE_INVENTORY.json record source and transformed-file hashes. Extraction scripts preserve local operation without copying the commercial application, hosted backend, billing, credentials, or private agent knowledge. DaVinci Resolve and its vendor scripting library are loaded from the user's installation and are not redistributed.

The public `skills/` tree is a separately reviewed AGPL-3.0-only editorial projection for the standalone package. `skills/manifest.json` records the exact files and hashes. Its technical instructions are grounded in the published SDK, CutAgent CLI reference, and local capabilities; adapted creative workflows exclude proprietary desktop execution and hosted-service dependencies. The private CutAgent Agent Knowledge and Creative Skill trees are not mirrored into this repository.
